# OpenMac Category Taxonomy & Architecture

OpenMac uses a structured, multi-tier categorization system designed to balance granularity with discoverability.

---

## 🎯 Categorization Principles

1. **Substance Over Novelty**: A category is only established if there are at least three distinct, active open-source projects satisfying its criteria.
2. **Platform Context**: Categories are defined around macOS workflows rather than generic Unix tools.
3. **Primary Intent**: Software is categorized according to its primary intended use case (e.g., a code editor with a built-in terminal is categorized under **Development**, not **Terminal**).

---

## 📚 Category Index

### 1. `development` — Development Tools
- **Scope**: Integrated development environments (IDEs), code editors, Git graphical interfaces, REST/GraphQL clients, SQL and database explorers, container engines, and local development virtualization.
- **Example Projects**: Zed, VSCodium, CotEditor, Bruno, Beekeeper Studio, Colima, Podman Desktop.

### 2. `terminal` — Terminal & Shell
- **Scope**: Terminal emulators, GPU-accelerated terminal apps, terminal multiplexers, prompt themes, shells, and CLI power utilities.
- **Example Projects**: iTerm2, Ghostty, Alacritty, Kitty, WezTerm, Starship, Zellij.

### 3. `window-management` — Window Management
- **Scope**: Binary space partitioning (BSP) tiling managers, manual tiling, keyboard window snappers, and window switcher enhancers.
- **Example Projects**: Rectangle, AeroSpace, yabai, Amethyst.

### 4. `productivity` — Productivity & Launchers
- **Scope**: Application launchers, clipboard managers, menu bar organizers, mouse/trackpad behavior enhancers, and screen capture tools.
- **Example Projects**: Maccy, AltTab, Ice, Hidden Bar, Sol, LinearMouse, Kap, Flameshot.

### 5. `system` — System & Hardware
- **Scope**: Hardware diagnostics, menu bar resource telemetry (CPU/GPU/RAM/network), uninstaller clean utilities, display DDC/CI brightness controls, and package managers.
- **Example Projects**: Stats, Pearcleaner, MonitorControl, Latest, Keka, Homebrew.

### 6. `ai-ml` — AI & Machine Learning
- **Scope**: Local LLM runners, desktop chatbot frontends, Core ML accelerated speech-to-text, and local image synthesis tools.
- **Example Projects**: Ollama, Jan, Chatbox, Whisper.cpp, DiffusionBee.

### 7. `media` — Media & Audio
- **Scope**: Modern media and video players, lossless audio routers, virtual audio loopbacks, video transcoders, and live streaming software.
- **Example Projects**: IINA, VLC, HandBrake, Audacity, LosslessCut, OBS Studio, BlackHole.

### 8. `security` — Security & Privacy
- **Scope**: End-to-end encrypted password managers, file and cloud vault encryption, personal host firewalls, persistence analyzers, and privacy browsers.
- **Example Projects**: Bitwarden, KeePassXC, LuLu, KnockKnock, Cryptomator, Tor Browser.

### 9. `notes` — Notes & Writing
- **Scope**: Local-first markdown editors, networked knowledge graphs, distraction-free writing software, and research note managers.
- **Example Projects**: Logseq, Joplin, AppFlowy, Zettlr, MarkText.

### 10. `file-management` — File Management & Sharing
- **Scope**: Local P2P AirDrop alternatives, cloud storage browsers, archive managers, and BitTorrent clients.
- **Example Projects**: LocalSend, Cyberduck, Transmission, Syncthing macOS.

### 11. `design` — Design & Creative
- **Scope**: Vector graphics illustration, 3D creation suites, digital painting, photo manipulation, and creative tools.
- **Example Projects**: Blender, Inkscape, GIMP, Krita.

### 12. `customization` — Customization & Tweaks
- **Scope**: Low-level keyboard remapping, event-driven menu bar widgets, mouse button customizers, and appearance tweaks.
- **Example Projects**: Karabiner-Elements, SketchyBar, SensibleSideButtons.
