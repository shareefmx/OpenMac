# Support & Community Help

Welcome to the **OpenMac** support guide. Here is how and where to seek assistance depending on what you need.

---

## ❓ Need Help Finding or Recommending an App?
If you are looking for an open-source alternative to a proprietary Mac application or want recommendations for specific workflows:
- Join the conversation on [GitHub Discussions](https://github.com/shareefmx/OpenMac/discussions).
- Browse categorized sections in [`README.md`](./README.md).

---

## 🚀 Proposing a New Project
- If you want to add an open-source macOS app or tool, please use our [Add Project Issue Form](https://github.com/shareefmx/OpenMac/issues/new?template=add-project.yml).
- Or follow our [Contribution Guide](./CONTRIBUTING.md) to submit a Pull Request.

---

## ⚠️ Reporting an Issue with a Listing
If an existing project in OpenMac has a broken URL, has transitioned to closed-source, or has outdated metadata:
- Submit a [Project Report Issue](https://github.com/shareefmx/OpenMac/issues/new?template=report-project.yml).

---

## 🛠️ Issues with a Listed Application Itself
**OpenMac is a directory, not the author or maintainer of the listed applications.**

If you encounter a bug, crash, or feature request in a listed app (e.g. IINA, Ghostty, Rectangle, Zed):
- Please file the issue directly in that specific application's source repository (linked in the table row under `Source`).

---

## 💬 General Inquiries & Maintainer Contact
For inquiries regarding directory governance, collaboration, or partnerships, feel free to open a thread on [GitHub Discussions](https://github.com/shareefmx/OpenMac/discussions).
